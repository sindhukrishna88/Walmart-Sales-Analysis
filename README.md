# Walmart Sales Analysis

## Project Overview

This project analyzes Walmart Global Superstore sales data to understand sales trends, profitability, customer behavior, regional performance, and future sales patterns.

The project is divided into two phases:

### Phase 1 – Sales Analysis

The analysis covers:

- Data preprocessing and cleaning
- Sales by product category
- Profitability vs. discounts
- Sales performance by region
- Sales behavior by customer segment
- Monthly sales trends from 2012 to 2015
- Top 3 countries by sales
- Customers with total sales above $4,000
- Minimum-performing categories and regions
- Quarterly analysis using the Order Date

### Phase 2 – Sales Prediction

Machine learning and deep learning techniques are used to predict quarterly sales for future periods.

Models included:

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- Neural Network

The prediction analysis uses year and quarter information and compares actual and predicted sales.
